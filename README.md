## Featured projects

### [Visual-cortex encoding and RSA](https://github.com/amityelin/algonauts-nsd-encoding-rsa)

An end-to-end analysis of how CLIP ViT-B/32 and ResNet-50 relate to human visual-cortex responses in the Algonauts 2023 dataset. It demonstrates nested cross-validation, ridge encoding, representational similarity analysis, permutation testing, reproducible configuration, automated tests, and CI.

**Tools:** Python, NumPy, pandas, scikit-learn, SciPy, PyTorch, Jupyter, GitHub Actions

### [Neural memorability prediction](https://github.com/amityelin/NeuralMemorabilityPredictor)

Exploratory modeling of image memorability from human fMRI and monkey electrophysiology data. The project covers data preprocessing, ROI-level statistical analysis, and experiments with support-vector and neural-network models.

**Tools:** Python, pandas, scikit-learn, PyTorch, statistical visualization, Jupyter

### [Representational drift in human V1](https://github.com/amityelin/rep_over_time_2_models)

A notebook pipeline for studying representational change over time in human primary visual cortex using NSD data and a steerable-pyramid encoding model. It includes image-feature extraction, pRF sampling, regression, permutation analysis, aggregation, and visualization.

**Tools:** Python, NumPy, HDF5, regression, permutation methods, computational neuroscience
